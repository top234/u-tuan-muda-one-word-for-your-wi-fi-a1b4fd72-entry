One word that describes home Wi-Fi: **Teenager**.

Home Wi-Fi behaves exactly like a teenager — moody, disappearing into its
room, only working when it feels like it, ignoring you completely. Everybody
recognises that behaviour instantly, and as a network name it is funny on
the spot.

## Run it

```sh
node main.ts
```

This writes the single word `Teenager` (8 characters, no trailing newline)
to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
